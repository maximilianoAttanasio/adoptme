# AdoptMe - Plataforma de Adopción de Mascotas

AdoptMe es una aplicación backend construida con Node.js, Express y MongoDB para gestionar la adopción de mascotas. Este proyecto permite a los usuarios registrar mascotas, adoptar animales y consultar información de adopciones mediante una API RESTful.

---

## Tecnologías Utilizadas

- **Node.js** + **Express**
- **MongoDB** (utilizando Mongoose)
- **Docker** para contenerización
- **Mocha** + **Chai** + **Supertest** para testing
- **Swagger** para documentación de API
